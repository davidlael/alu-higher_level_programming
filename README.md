# Python - Almost a Circle

## Description
This project reviews object-oriented programming concepts in Python including inheritance, encapsulation, property getters and setters, class methods, static methods, serialization, and deserialization with JSON and CSV files.

## Files
* `models/base.py`: Base class for the project.
* `models/rectangle.py`: Rectangle class inheriting from Base.
* `models/square.py`: Square class inheriting from Rectangle.
* `tests/`: Directory containing unit test suites.
