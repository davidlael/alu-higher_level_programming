# Python - Almost a Circle

Review project covering classes, inheritance, unit testing, JSON
serialization/deserialization, CSV, and `*args`/`**kwargs` in Python 3.

## Files

- `base.py` - `Base` class: manages `id` and provides JSON/CSV
  serialization helpers (`to_json_string`, `from_json_string`,
  `save_to_file`, `load_from_file`, `save_to_file_csv`,
  `load_from_file_csv`, `create`).
- `rectangle.py` - `Rectangle` class, inherits from `Base`.
- `square.py` - `Square` class, inherits from `Rectangle`.
- `tests/` - Unit tests for all modules, classes, and methods.
